# Aperçu des icônes

Les icônes du jeu sont dessinées par le code (`Assets/_Fief/Scripts/UI/IconArt.cs`).
Pour les voir toutes sans ouvrir Unity :

```
cd Tools/icones
dotnet run -- planche.png
```

`planche.png` montre les 64 icônes. Pour en voir quelques-unes en grand :

```
dotnet run -- grand.png couronne,ailes,pousser
```
